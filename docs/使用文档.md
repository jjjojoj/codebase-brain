# Codebase Brain 使用文档

当前 `main` 分支是稳定 MVP。详细安装、MCP 配置、工具清单和使用流程见
项目根目录的 `README.md`。

稳定版只推荐使用三类能力：

- 项目约定检索。
- 手动记录的轻量会话记忆。
- Git 只读上下文工具。

以下能力暂不推荐给公司开发者使用：

- Git 历史向量索引。
- Git 历史语义搜索。
- legacy `packages/*` 多 MCP server 入口。
- 自动 watch / 自动同步。

明确不做：

- OpenAI / 云端 embedding provider。当前产品路线只使用本地 `sentence-transformers` 或本地/内网批准的 Ollama。

如果需要参考原实验版设计，请查看 `dev` 分支。
