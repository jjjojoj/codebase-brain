# 错误处理约定

## 目标
统一模块内错误的定义、传播和记录方式，让调用方可以稳定处理失败场景。

## 约定
- 对外暴露的函数返回明确的错误类型或结构化错误对象。
- 捕获异常时保留原始上下文，日志中记录关键参数和关联 ID。
- 不吞掉异常；无法恢复的错误应向上抛出或转换为统一错误响应。
- 用户可见的错误信息保持简洁，内部调试信息只写入日志。

## 示例
当认证失败时，返回 `AUTH_INVALID_CREDENTIALS`，不要返回数据库或第三方服务的原始错误。
